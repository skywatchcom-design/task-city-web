How to stop procrastinating on homework: start with a five-minute first step

Updated November 16, 2026

In short: SkyTasks is a free planner for students with a focus mode that shows one task, its first small step and a short timer, because homework gets put off when the task on the list is too big to start. The fix works with or without an app: never write "do the history essay". Write the first step you can start in five minutes, like "open the file and write the title", and start a timer for just that.

Why homework gets put off

The list says "study" or "essay". Your brain reads that as an hour of effort with no clear beginning, so it picks the group chat instead. A task you can start in five minutes is one you actually start, and once you are in it the next step is easy. The problem is rarely laziness. It is the size of the first step.

What to do tonight

  1. Pick one task. Not the whole list. The one that is due first.
  2. Write its first five-minute step. "Read the question twice and underline what it asks." "Copy the first exercise into the notebook." If the step still feels big, make it smaller.
  3. Set a timer for two or ten minutes. You are allowed to stop when it rings. Most people do not.
  4. Mark the step done, and write the next one. Each small step done makes the next one easier to start.
  5. Plan the first step of tomorrow tonight. Then tomorrow starts without a decision.

Common questions

How do I start homework when I have no motivation?

Do not wait for motivation. Make the first step so small that it needs none, like opening the book to the right page, and set a two-minute timer. Starting is the hard part, and a tiny first step removes it.

Which app helps with procrastination on homework?

SkyTasks has a focus mode built for this: one task on the screen, a small first step, a 2, 10 or 25 minute timer, and a smaller step when you are stuck. It is free on iPhone and Android, and every finished task builds a city you can look at.

Is it better to do the hardest homework first?

Do the one due first, and start it with its easiest step. Order by deadline, start by size. Putting the hardest subject first often means nothing gets started at all.
