# העוזר החכם של SkyTasks: הקמה בעלות אפסית

## מה יש כאן

| קובץ | מה הוא עושה |
|---|---|
| `supabase/migrations/20261028120000_ai_quota.sql` | טבלאות מכסה ופונקציות שסופרות שימושים: למשתמש, לכתובת IP ולכל המערכת |
| `supabase/functions/ai-assist/index.ts` | השרת: בודק התחברות ומכסה, קורא ל-AI ומחזיר תשובה |
| `supabase/functions/ai-assist/core.ts` | ההנחיות למודל, שרשרת הספקים החינמיים ובדיקת התשובות |
| `supabase/functions/ai-assist/core_test.ts` | בדיקות: `deno test core_test.ts` |
| `ai/flutter/ai_assist.dart` | הקובץ שנכנס לאפליקציה: `brainDump` ("שפוך הכול"), `breakDown` ("פרק לי את זה"), `unstick` (דחייה בלי אשמה) |

## 💰 למה העלות אפסית

1. **אף ספק AI לא מקבל כרטיס אשראי.** בלי חשבון חיוב אין למי לחייב. כשהמכסה החינמית נגמרת, הספק מחזיר "מלא" (429) ולא חשבונית.
2. **Supabase נשאר בתוכנית החינמית.** בתוכנית החינמית אין חיוב על חריגה: אם עוברים את המכסה, השירות נעצר ולא מגיע חשבון. המכסה כוללת 500,000 הפעלות של Edge Functions בחודש.
3. **שלוש תקרות משלנו**, כדי שלא נגיע אפילו לגבול של הספקים:
   - 10 שימושים ביום לכל משתמש (`AI_DAILY_LIMIT_PER_USER`)
   - 60 ביום לכל כתובת IP (`AI_DAILY_LIMIT_PER_IP`), נגד בוט שפותח הרבה חשבונות
   - 1,000 ביום לכל המערכת (`AI_DAILY_LIMIT_GLOBAL`)
4. **גיבוי חינמי:** אם המכסה של Gemini נגמרה, הבקשה עוברת ל-Groq ואחר כך ל-Cloudflare. כל אחד מהם חינמי ובלי כרטיס, ומספיק לחבר אחד מהם.
5. **מתג כיבוי:** `supabase secrets set AI_ENABLED=false` מכבה את ה-AI מיד. האפליקציה ממשיכה לעבוד כרגיל.

> ⚠️ המכסות של השכבות החינמיות משתנות מדי פעם. כדאי לבדוק מה המכסה היומית בדף ה-Rate limits של כל ספק, ולקבוע את `AI_DAILY_LIMIT_GLOBAL` מתחת לסכום שלהן.

## 🔒 למה אי אפשר לפרוץ דרכו

- **מפתחות ה-AI** נשמרים רק כ-secrets ב-Supabase. הם לא נמצאים בריפו, לא באפליקציה ולא בדפדפן.
- **רק משתמש מחובר** יכול לקרוא לפונקציה, עם טוקן שנבדק מול Supabase Auth.
- **המונים מוגנים:** הטבלאות פתוחות רק לשרת. משתמש לא יכול לאפס לעצמו את המכסה, וזה נבדק.
- **ל-AI אין גישה לכלום:** הוא לא רואה את מסד הנתונים, לא יודע מי המשתמש ומקבל רק את הטקסט.
- **התשובה מסוננת:** השרת מעביר רק שדות מוכרים (כותרת, תאריך, שעה, עדיפות), בודק פורמט ומגביל אורך. כל השאר נזרק.
- **המשתמש מאשר** כל הצעה לפני שהיא נשמרת.
- **הגבלת קלט:** עד 1,200 תווים ב"שפוך הכול" ועד 300 בשאר המצבים.

## 🛠 הקמה (פעם אחת, כרבע שעה)

1. **מפתח Gemini:** נכנסים ל-aistudio.google.com, לוחצים Get API key ויוצרים מפתח בפרויקט **בלי Billing**.
2. **(מומלץ) גיבוי Groq:** נכנסים ל-console.groq.com ויוצרים API key בתוכנית Free, בלי כרטיס.
3. **(אופציונלי) גיבוי Cloudflare:** ב-dash.cloudflare.com יוצרים API token עם הרשאת Workers AI, ומעתיקים את ה-Account ID.
4. **פריסה:**
   ```bash
   supabase login
   supabase link --project-ref wlsvwtvinopzuodpmqsj
   supabase db push
   supabase secrets set GEMINI_API_KEY=... GROQ_API_KEY=...
   # אופציונלי: CF_API_TOKEN=... CF_ACCOUNT_ID=...
   supabase functions deploy ai-assist
   ```
5. **באפליקציה:** מעתיקים את `ai/flutter/ai_assist.dart` ל-`lib/` וקוראים לפונקציות:
   ```dart
   final r = await AiAssist().breakDown('לעשות מס הכנסה');
   if (r.ok) { /* מציגים את הצעדים לאישור */ }
   else      { /* "העוזר החכם נח, נתראה מחר 🌙" */ }
   ```

הגדרות נוספות (לא חובה): `AI_ALLOWED_ORIGINS` (ברירת המחדל: האתר שלכם ב-GitHub Pages), `GEMINI_MODEL`, `GROQ_MODEL`, `CF_MODEL`.

## 📄 פרטיות: חובה לפני ההשקה

בשכבה החינמית של Gemini, גוגל רשאית להשתמש בטקסט שנשלח כדי לשפר את המודלים. לכן:
- מוסיפים ל-`privacy.html` סעיף כמו: *"כשאתה משתמש בעוזר החכם, טקסט המשימה בלבד (בלי שם, אימייל או מזהה) נשלח לספק AI חיצוני (Google / Groq / Cloudflare) לעיבוד, וייתכן שישמש לשיפור השירות שלהם."*
- בהגדרות האפליקציה מוסיפים מתג "עוזר חכם" שאפשר לכבות.
- לפני השימוש הראשון מציגים הודעה קצרה למשתמש.
